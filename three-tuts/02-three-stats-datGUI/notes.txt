FIX FPS issues - it was slower in Chrome for me (20fps)....
I had disabled hardware acceleration at some point in Chrome > Settings > System
But still slower than Firefox, running at 30fps instead of firefox's 60!
So I LIMITED the framerate so it maxes out at 30fps
... solution from here: https://stackoverflow.com/questions/11285065/limiting-framerate-in-three-js-to-increase-performance-requestanimationframe



This is fine to do as long as you are not doing VR for headsets, in which case you need 60fps min

CODE:
    setTimeout(function () {

        requestAnimationFrame(animate);

    }, 1000 / 30);


However, it causes stuttering on mobile, so we can check to see if the user is on a mobile device and - if not - limit the framerate

    // If on a browser, limit framerate to 30fps by moving animation frame to a timeout function 
    // This causes stuttering on mobile so you have to do a userAgent query to check
    if (
        navigator.userAgent.match(/Mobi/i) ||
        navigator.userAgent.match(/Android/i) ||
        navigator.userAgent.match(/iPhone/i)
    ) {
        // Current device is a mobile device
        // do not limit framerate
    } else {
        // Device is a browser - limit framerate
        setTimeout(function () {

            requestAnimationFrame(animate);

        }, 1000 / 30);
    }

This is another way to code it
    if (!navigator.userAgent.match(/Mobi/i) &&
        !navigator.userAgent.match(/Android/i) &&
        !navigator.userAgent.match(/iPhone/i)
    ) {
        // Device is a browser - limit framerate
        setTimeout(function () {

            requestAnimationFrame(animate);

        }, 1000 / 30);
    }
